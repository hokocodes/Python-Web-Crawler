## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Beautiful Spoup
- **Version Control:** Git and GitHub
- **Hosting:** Local
- **Code Editor and tools**: VS Code

 <br />

## Overview 🔨

This is a simple web crawler that outputs a CSV of found image URLs using python's beautiful soup library when inputting a url in the console.

## Set up
Please install all the packages and libraries required.<br>
```pip install -r requirements.txt```

## Run app
Then, run the app.<br>
```python crawler.py```
